🧠 What is Local State Storage?
In React, local state means the data is only stored in memory while the form is open. When you reload the page or navigate away, the data is lost.

For example:

const [formData, setFormData] = useState({...});
This stores your inputs in browser memory — useful for simple edits or temporary forms. But for Door Hub, you'll want persistent storage, like:

Option	Description	Persistence
Local State	Temporary, only in memory	❌ Not saved on refresh
API + Backend DB	Data is sent to backend and saved in PostgreSQL	✅ Long-term
LocalStorage / IndexedDB	Saved in browser	✅ But user-specific and limited
