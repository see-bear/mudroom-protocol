✅ You're in the home stretch — this is a very common (and easy-to-fix) Python 3.11+ issue related to dataclasses.

❌ The Error Explained
ValueError: mutable default <class 'list'> for field line_numbers is not allowed: use default_factory


This means one of your @dataclass fields looks like:

@dataclass
class BlockMetadata:
    line_numbers: list = []


That empty list [] is mutable, which Python now disallows unless you wrap it properly.

✅ The Fix

You need to use field(default_factory=...) instead of a raw list:

from dataclasses import dataclass, field

@dataclass
class BlockMetadata:
    line_numbers: list = field(default_factory=list)


This tells Python to create a new list for each instance (not reuse the same one for all).
